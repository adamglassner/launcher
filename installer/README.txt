IRONITE LAUNCHER  (v@VERSION@)
An Ironite collection. (c) 2026 Ironite.
====================================================

Open "Ironite Launcher" from your desktop or Start menu.
The launcher opens in its own window (it uses Microsoft Edge, built into
Windows 10 and 11) and shows every Ironite game.

GAMES
Every game is downloaded from its own GitHub repository. Click Install on a
game and the launcher downloads its latest release, installs it and adds it
to Installed. When a new version of an installed game comes out, the
launcher updates it automatically (never while you're playing). You can turn
automatic updates off on the About page and update games yourself.

- Card Games: Klondike, Texas Hold'em, Blackjack, Go Fish, Old Maid, Euchre
- Hidden Object: Maple Lane Finds
- Arcade: Solar Siege
- Puzzle: Snugfit
- Board Games: Chess, Checkers
- Simulation: Rewind Life (free DEMO)
- Education: The Appalachian Trail
- Idle: Dookie Clicker (web game: plays online in its own window, nothing
  to install)

COMING SOON
- Card: Hearts, Spades, Cribbage, Gin Rummy
- Word/Trivia
- Simulation: Lifeboat Simulator, Prison Cell Simulator, Big Top Builder,
  Carnival Constructor
- Board Games: Mahjong

The launcher counts how many times you open each game and how long you play.

UPDATING THE LAUNCHER
The launcher checks github.com/adamglassner/launcher for new versions. When
one is out, a banner offers to update: click Update now and the launcher
closes, updates and opens again (Windows asks for permission first).

PLATFORMS
Ironite Launcher runs on Windows 10 and 11. macOS and Linux versions of
the launcher are coming soon. Each game lists the systems it plays on.

VERSIONS
The launcher's version is shown in the bottom-left corner. Click it (or
choose What's New) to see the changelog. The full changelog is also in
CHANGELOG.txt in this folder.

UNINSTALLING
Settings > Apps > Installed apps > Ironite Launcher >
Uninstall, or use "Uninstall" in the Start menu's Ironite folder.

If Windows shows "Windows protected your PC" when you run Setup, click
"More info" then "Run anyway" - the installer is not code-signed yet.
